Build & train embedding model
content-based filtering

Encodes 40 Indian movies as feature vectors (genre, era, language, mood, rating). Trains a dense autoencoder to learn a 6-dimensional latent space — similar movies cluster together. 

// Each movie → 14-dim feature vector
// [genre_onehot×6, language×3, era×2, mood×2, rating_norm]
const encoder = tf.sequential({
  layers: [
    tf.layers.dense({ inputShape:[14], units:10, activation:'relu' }),
    tf.layers.dense({ units:6 }),             // latent space
    tf.layers.dense({ units:10, activation:'relu' }),
    tf.layers.dense({ units:14, activation:'sigmoid' })  // reconstruct
  ]
});
model.compile({ optimizer:'adam', loss:'meanSquaredError' });
