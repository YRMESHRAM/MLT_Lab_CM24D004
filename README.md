# 📖 Course Overview

This repository contains all laboratory work completed for the **Machine Learning Tools Lab** course.

The main objective of this lab is to understand the fundamentals of **Machine Learning** and implement models using **TensorFlow.js** directly in the browser environment.

The lab focuses on:

- Understanding Machine Learning concepts  
- Building models using **TensorFlow.js**  
- Training models in the **browser environment**  
- Evaluating predictions and results
