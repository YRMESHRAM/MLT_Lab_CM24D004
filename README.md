# 📖 Course Overview

This repository contains all laboratory work completed for the **Machine Learning Tools Lab** course.  
The main objective of this lab is to understand and implement **Machine Learning concepts using TensorFlow.js** in browser-based applications.

The experiments focus on:

- Understanding Machine Learning fundamentals  
- Implementing ML models using **TensorFlow.js**  
- Running models directly in the **browser environment**  
- Training, evaluating, and deploying ML models on web applications  

---

# 📂 Repository Structure

The repository is organized into different folders based on the experiments performed during the lab sessions.

| Folder | Description |
|------|-------------|

| 📁 **Practical1** | Linear Regression implementation using TensorFlow.js |

| 📁 **Practical3** | Text Sentiment Analysis using RNN / Pre-trained model |

---

# 🧠 Practical Implementations

### 📌 Practical 1 – Linear Regression
Implementation of a basic **Linear Regression model** using TensorFlow.js to understand how models learn relationships between variables.

### 📌 Practical 2 – Digit Recognition (MNIST)
Training a **Convolutional Neural Network (CNN)** on the MNIST dataset to classify handwritten digits.

### 📌 Practical 3 – Sentiment Analysis
Building a **text sentiment classifier** to determine whether a sentence expresses **positive or negative emotion**.
